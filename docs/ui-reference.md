# UI reference — Midnight Ledger (admin / POS)

## Reference

- Niche: multi-tenant commerce operations (Shopify/Magento admin density)
- URLs: Google Stitch project OmniCommerce Admin & Delivery; Shopify Admin information architecture
- Mood: dense, ledger-like, midnight + gold, operational, restrained futurism

## Color

- Background layers: `#f8fafc` (base), `#ffffff` (elevated), `#0f172a` (sidebar)
- Text primary / secondary / muted: `#0f172a` / `#334155` / `#64748b`
- Accent: `#c9a227` (CTA, status, focus) — decorative gold-muted `rgba(201, 162, 39, 0.15)`
- Border: `#e2e8f0`
- Semantic: success `#16a34a`, warning `#d97706`, danger `#dc2626`

## Typography

- Font: Inter / Geist, 13px body, 12.5px tables
- Headings: semibold; body regular; tabular nums for money

## Layout

- Sidebar ~240px; dense tables row ~36px; page padding 16–24px

## Components

- Primary button: midnight fill, gold on hover optional
- Cards: 1px border, little shadow
- Inputs: 1px border, gold focus ring

## Motion

- See `.cursor/skills/anioam/SKILL.md` (150–250ms, reduced motion)
